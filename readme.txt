AI Excuse Generator Bot

Telegram бот для генерації готових повідомлень та виправдань за допомогою AI.
Користувач обирає отримувача повідомлення, причину та стиль, після чого бот генерує короткий готовий текст українською мовою. Бот працює на Aiogram та використовує DeepSeek через OpenRouter API.

## Можливості

- Генерація повідомлень через AI
- Різні стилі повідомлень
- Зручний Telegram інтерфейс
- Підключення API через `.env`

## Технології

- Python
- Aiogram 3
- OpenRouter API
- DeepSeek Chat
- python-dotenv
